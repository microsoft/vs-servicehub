# Overview

Microsoft.ServiceHub.Framework is a collection of packages for .NET and Node.js that provides brokered service infrastructure, which facilitates IPC between processes running on the same machine or over a network.

Install the .NET package from NuGet:

[![NuGet package](https://img.shields.io/nuget/v/Microsoft.ServiceHub.Framework.svg)](https://www.nuget.org/packages/Microsoft.ServiceHub.Framework)

```console
dotnet add package Microsoft.ServiceHub.Framework
```

## Highlights

- Proffer and consume brokered services in-process or across processes using the [.NET framework](docs/framework.md).
- Exchange brokered services with [Node.js](docs/npm.md).
